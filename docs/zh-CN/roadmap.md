# 路线图

[English](../en/roadmap.md) | 中文

Loushang 保持一个主品牌，同时逐步发展多个产品面。第一个稳定产品面是 `loushang code`。

## V1：Loushang Code

围绕 CLI/TUI session、模型路由、工具、扩展、方法、诊断和导出，建立真实可用、可验证的 coding 工作闭环。

## V2：Loushang Work

把 `code` 放回更广义的个人复杂工作工作台下，让 `research` 和 `ppt` 成为真实专业工作面，而不只是面向未来的名称。

## V3：Daemon、Market、Gateway

增加连续性、后台运行基础、方法市场机制和模型网关用量计量。

## V4：Team

支持 shared runs、team methods、approvals、team budgets 以及 audit/governance surface。

## V5：Managed

走向面向方法绑定复杂工作的 managed runtime，而不是简单托管通用 agent。
