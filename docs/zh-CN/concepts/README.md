# 核心概念

[English](../../en/concepts/) | 中文

Loushang 面向复杂工作组织，而不仅仅是模型调用。

## 方法

方法是一种可复用的工作运行方式。它可以定义阶段、指导、角色、预期工作产物和验收标准。长期目标是让方法成为可执行、可改进的资产，而不是静态流程文档。

## 会话

会话是一次 coding 交互的持久记录。它保存消息、工具事件、模型用量、诊断信息，以及后续恢复或检查工作所需的上下文。

## 工具

工具是提供给 agent 的可执行能力。工具应受到策略治理，并在 transcript 中清楚呈现。

## 扩展

扩展是为 coding session 贡献行为的项目级 Python 代码。扩展可以添加 hooks、工具、动态资源、命令和 flags，而不需要修改核心产品代码。

## 模型 Provider

模型 provider 组合了 provider 身份、endpoint 语义、模型能力、认证、默认值、兼容规则和价格元数据。Loushang 通过模型 catalog 解析这些信息，使上层不需要硬编码每个 provider 细节。

## 工作产物

工作产物是对交付有意义的输出：代码变更、review notes、导出文件、计划、研究总结或其他 artifacts。Loushang 的路线图将工作产物和验收条件作为复杂工作的一等组成部分。
