# Loushang 文档

[English](../en/) | 中文

Loushang 是一个把复杂工作变成可运行流程的智能工作系统。本套文档优先覆盖当前可以使用的能力：`loushang code` 以及底层 `loushang.ai` SDK。

## 按目标阅读

- [快速开始](./getting-started/)：从源码安装、配置模型、运行第一条 prompt。
- [使用手册](./user-guide/)：使用 CLI、TUI、会话、命令、工具、扩展、方法和诊断能力。
- [核心概念](./concepts/)：理解方法、会话、工具、扩展和模型 provider 背后的产品模型。
- [AI SDK](./sdk/)：直接使用 `loushang.ai` 做模型查询、流式输出、工具调用、provider 适配和成本估算。
- [示例](./examples/)：查找 coding session 和 AI SDK 的可运行示例。
- [参考手册](./reference/)：查询 CLI flags、配置、环境变量、模型 catalog、slash commands 和 session 文件。
- [路线图](./roadmap.md)：了解当前重点和后续产品面。
- [贡献指南](./contributing.md)：了解这个早期项目的贡献约定。
