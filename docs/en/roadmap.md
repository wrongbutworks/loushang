# Roadmap

English | [中文](../zh-CN/roadmap.md)

Loushang has one primary brand and multiple product surfaces. The first stable product surface is `loushang code`.

## V1: Loushang Code

Build a real, usable, verifiable coding work loop around CLI/TUI sessions, model routing, tools, extensions, methods, diagnostics, and export.

## V2: Loushang Work

Bring `code` back under a broader personal complex-work workbench. Make `research` and `ppt` real specialized work surfaces instead of only future-facing names.

## V3: Daemon, Market, Gateway

Add continuity, background runtime foundations, method market mechanics, and model gateway usage accounting.

## V4: Team

Support shared runs, team methods, approvals, team budgets, and audit/governance surfaces.

## V5: Managed

Move toward a managed runtime for method-bound complex work, not merely hosted generic agents.
