# Loushang Documentation

English | [中文](../zh-CN/)

Loushang is a method-native AI work system. This documentation focuses on what can be used today: `loushang code` and the underlying `loushang.ai` SDK.

## Read By Goal

- [Getting Started](./getting-started/) - install from source, configure a model, and run the first prompt.
- [User Guide](./user-guide/) - use the CLI, TUI, sessions, commands, tools, extensions, methods, and diagnostics.
- [Concepts](./concepts/) - understand the product model behind methods, sessions, tools, extensions, and model providers.
- [AI SDK](./sdk/) - use `loushang.ai` directly for model lookup, streaming, tool calls, provider adapters, and cost helpers.
- [Examples](./examples/) - find runnable examples for coding sessions and the AI SDK.
- [Reference](./reference/) - look up CLI flags, configuration, environment variables, model catalog shape, slash commands, and session files.
- [Roadmap](./roadmap.md) - understand current focus and future product surfaces.
- [Contributing](./contributing.md) - understand contribution expectations for this early project.

## Internal Notes

Design and implementation history lives in [Internal Architecture And Design Notes](../internals/). Those documents are useful for contributors, but they are not the recommended first path for users trying Loushang.
