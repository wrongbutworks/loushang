# Provider evidence: deepseek

- Verified at: 2026-06-22
- Issue: #104
- Official docs:
  - https://api-docs.deepseek.com/
  - https://api-docs.deepseek.com/quick_start/pricing
  - https://api-docs.deepseek.com/guides/thinking_mode
  - https://api-docs.deepseek.com/api/create-chat-completion
- Authentication: API key in `DEEPSEEK_API_KEY`, sent as an `Authorization: Bearer ...` header.
- Endpoint: `https://api.deepseek.com`, OpenAI-compatible Chat Completions protocol.
- Included models:
  - `deepseek-v4-flash`: faster DeepSeek V4 model for lower-cost general work.
  - `deepseek-v4-pro`: stronger DeepSeek V4 model selected as the default chat model.
- Verified capabilities:
  - API docs establish the selected base URL and OpenAI-compatible Chat Completions path.
  - Pricing docs list both selected models with 1,000,000 token context, 384,000 maximum output tokens, thinking support, tool calls, JSON output, streaming, and context caching.
  - Thinking-mode docs state `high` and `max` thinking budgets; this catalog maps `low` and `medium` to `high`, and `xhigh` to `max`.
  - Pricing docs record DeepSeek V4 Flash at $0.14 input, $0.0028 cache hit, and $0.28 output per million tokens.
  - Pricing docs record DeepSeek V4 Pro at $0.435 input, $0.003625 cache hit, and $0.87 output per million tokens.
- Unknown/omitted facts:
  - Older R1, V3, and V3.2 model names are omitted because the current official pricing page lists V4 Flash and V4 Pro as the selected current API models.
  - Image input is not represented because the cited official DeepSeek API docs list the selected models as text models.
  - `cacheWrite` is omitted because pricing documents cache-hit prices, not a separate stable write price for this catalog shape.
