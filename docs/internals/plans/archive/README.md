# Archived Plans

## Status

Historical execution records.

This directory contains implementation plans that have been completed, superseded,
or paused. They are retained to preserve decision and execution context.

## Reading Rule

- Use archived plans to understand how a feature was originally approached.
- Do not use archived checklist state as current implementation status.
- Prefer current code/tests for behavior and current architecture docs for
  component boundaries.
- Old paths and old terminology are historical unless a current plan explicitly
  reopens the work.
