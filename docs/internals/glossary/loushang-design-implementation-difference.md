# Loushang Design-Implementation Difference Terms

## Scope

本文定义 `loushang` 架构设计与代码实现对照时使用的一组术语。

它主要用于：

- 架构评审
- 设计与实现对照分析
- 文档写作中的差异分类

---

## Design-Implementation Difference

`设计-实现差异` 是架构设计与代码/测试之间任何不一致的总称。

它是总术语，不直接表达差异性质；具体分析时，应进一步细分为以下类型。

### 缺失

设计中已有明确对象、边界或能力，但代码与测试中尚无对应实现。

### 偏离

设计中已有明确对象、边界或能力，代码中也有实现，但实现形态、职责归属或交互方式与设计不一致。

### 部分落地

设计已被部分实现，但尚未达到设计表达的完整边界或能力范围。

### 未建模实现

代码与测试中已经存在某项实现，但架构设计中尚未对其建模或表达。

### 文档过时

文档表达的设计口径已经不是当前接受的设计口径。

### 漂移

设计-实现差异长期未被处理，导致事实架构逐渐脱离目标架构的状态。

---

## One-Line Rule

- 没实现，叫 `缺失`
- 实现了但不一样，叫 `偏离`
- 实现了但没完整到位，叫 `部分落地`
- 代码有但设计没写，叫 `未建模实现`
- 文档落后于当前接受的设计，叫 `文档过时`
- 差异长期积累导致事实架构脱离目标架构，叫 `漂移`
